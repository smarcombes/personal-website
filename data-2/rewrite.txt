# [Why section] Personal storage has a design problem 

## The pains
- Storage is a mess
- Sync is a pain in the ass
- Backup is never something you want to think about
- Dropbox-like Cloud solutions enable to sync a folder the size of a USB key, not much more. 
- I'd like to sync files without having it impact my privacy
- The files are mine. I don't want to rent them.

## The underlying design problem

// Explain here how personal storage as it is conceived today is designed to work exactly like the hardware underneath and not in a natural way. 
// Every device has its own hard drive, where I can put things like in a shoebox. I cannot have the same things on two devices except if I manually sync them by copying files from one to the other and manually ensuring they have hte same orga. And even if I do that, then I'm limited by the space of my local hard drive. I can buy another hard drive or I can buy a cloud bucket or a dropbox account, but it's yet another bucket. 
End of the day: files everywhere, everything scattered, sync only of small cloud folders, no real hegemony between my devices. 
But tech has what we need to make things better: decentralized filesystems, high speed internet connections, wifi, etc
Other problem: the privacy concern. Very real at the time as people were not comfortable putting everything in dropbox

# Design decisions

The ideal state: 
- Unify storage spaces into one --> One single, unified storage space
A user can have N devices. They should all display exactly the same files. Regardless of their shape, OS, storage capacity. 
If I have a file on my Desktop on my Mac, it should be on my desktop on my Windows PC. 
- Make that storage liquid --> Add storage to get more storage, not to get another shoebox to sync files to
When I buy a harddrive, I want it to expand the storage available to me transparently. I don't want to care whether.
- Local/Cloud, location of storage, backup: make it natural by enabling the user to plug in anything
If I don't want hardware at home and can afford Cloud, I want to be able to add a bucket. If I want privacy, I want to be able to replace that with a hard drive.

The new system: 
We split file presentation and file storage:
- File presentation: 
	- the same on all devices. All devices show the same files and folders, whatever the number of files and whatever their capacity
	- file transfer becomes instant, because transferring a file is just about transferring its metadata and where to download the ressource
- File storage
	- the source of truth for data is a backend storage pool, which can be made of multiple Network Attached Storage devices (NAS) or Cloud buckets. This backend storage stores ALL the files of the users, multiple times (so it can recover from failures)
	- the local hard drive of each device is just used as a cache: each device picks the files the user is most enclined to use and stores a cached version of them up to the capacity of its hard drive. The user can access cached files as easily as local files, while the other files stream from other sources
	- storage is fully decentralized, so all devices work together when user is trying to accdess a file


# The tech 

Had to invent & re-imagine entire layers of the stack for the vision to happen. 
1. We made a fully decentralized, fully P2P virtual filesystem. Implemented in C. Running on Android, iOS, Liux, MacOS and Windows. 
Features: showing the same eventually synchronized file tree on all devices, handling torrent-like data movement between devices, handling rules to make sure the backend pool always had a copy of each file, and that each file was at minimum stored on two nodes. Fully encrypted, end to end.
2. We created an app to serve as filesystem UI on mobile
3. We "hacked" the MacOS Finder and Windows Explorer to adapt to the new paradigm of how we apparoched files: ability to see a file that is not there on your device, progress feedback on the icon when clicking a file, ability for the user to distinguish between 'pinned' files (the ones that stay on your device when offline) and the others. Ability of the explorer/Finder to show non-accessible files as disabled/grayed-out when offline
4. We designed, built an productized a zero setup NAS dongle. Plug it to your router, plug a drive to it. Boom. You have more storage.
