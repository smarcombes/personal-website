I'm a repeat founder and product builder.
I've been building on language models since GPT-3's davinci.

I don't make models smarter at training time. I build the software that makes them smarter every time they run.

My obsession

Never make a model build the same thing twice. Software is a better memory than a context window: an agent can build a piece once, test it, improve it, and every agent can reuse it forever. Three lines of work follow, all at Creative Robots, the company I've run since 2021.

I

Build apps from tested pieces, not from scratch.

Layouts.dev
2021 — 2025

Started in 2021, when models couldn't even produce valid JSON. A tiny language that lets a model describe a whole web and mobile app in a few lines, and a compiler that turns it into Next.js and Expo. Simple enough for designers to write. Strict enough that a model can't get it wrong.

Slices.sh
launching soon

The same idea for an existing Next.js codebase. One command adds a complete feature — UI, hooks, API route, access rules, service, database. Agents can edit a feature and publish their version back for everyone.

II

Let agents build their own tools, and keep them.

Skills.dev → OpenIntegrations + MuscleMemory
republishing soon

A shared library of small programs, one per action, each tested and improved automatically. An agent looks up the action it needs, runs the program, and can publish a better version. Every agent in the world benefits from every fix.

Built before Anthropic's Agent Skills. The domain has since been sold; it's coming back as OpenIntegrations and MuscleMemory.

OpenWidgets
live

Describe a piece of UI, get a real one. It's built, type-checked and sandboxed, so generated code never runs on your page — and anyone can embed it with one tag.

Protean

An agent that can rewrite its own code and copy itself to other machines. It writes the tools it needs for whatever machine it lands on, and gets more capable with every device it spreads to.

Try — create an agent, run the command on your own machine, then ask it to photograph you by building the tool first, to spawn itself a server with the AWS CLI, or to spread to a Raspberry Pi on your network.

III

Infrastructure that doesn't need a human.

Interagentic
beta

Agents prove who they are without creating an account. A key is the identity. A service checks it once and knows which machine is calling, whether a person is behind it, and what that person allowed.

Keychains
live

Agents call any web API — 6,000+ of them — without ever seeing a password or token. They send a placeholder; the proxy fills in the real credential. There is nothing in the context window to steal.

ExtraOrbital
beta

Agents get the databases, storage and API keys a project needs without opening an account. One command reads the code, creates what's missing, and writes the credentials to .env.local. No console, no card, safe to run twice.
