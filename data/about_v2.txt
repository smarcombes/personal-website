# Thesis
- The tech stack is too complex for AI, because it is too complex for humans / Tech teams are incredibly unefficient. They were so since well before AI.
- Our approach to AI intelligence is wrong / AI will be so much better if we gave it the tools we use for ourselves / (software based > token based)
- Intelligence is here. Now we need better tools
- LLMs can produce software. They would be so much more efficent at building software factories. / AI at build time is much better that AI at run time / Don't use AI to build software. Use it to build software factories. 
- MCPs are dog shit. We need a better way for humanity to teach AI how to do things.
- From learn by copying, to learn by reasoning, to learn by trying & iterating / AI needs a way to learn at runtime. It doesn't need AI for that.
- Software as a means for AI to program its brain.
- Tool vibe-coding as a learning mechanism
- Meet the living software stack
- Permissions are the main break against a more useful AI. Approching them as a live system may help.
- Building context as a background live loop
- Security at the AI area: antivirus vs boundaries
- Building software that morphs itself
- A DST for GenUI is so much better that pure react
- Infra is not ready for the AI area. (Interagentic)
- Bye, user signup. Hello self-registration
- We're missing a feedback loop plateform for non-AI-researchers (normal users
- Welcome to the unstructured, self-documented API?
- Developers: Don't build a machine. Build a living organism
