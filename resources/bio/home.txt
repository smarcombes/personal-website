# Recent work: 
## Creative Robots
Experimenting at the intersection of Design x App development x AI-powered tools. 
Initially working on a vibe-coding app (before ChatGPT launch). Then set out to build an approach more adapted to designers and developers in the field. 
I call it rail-coding. 
The main output of that is Layouts.dev, a pure software solution which outputs complete NextJS and Expo projects from a simple DSL: intuitive enough for designers to use in place of Figma, and text-based so AI agents can easily play with it. 

## Interagentic
A company focused on giving agents more qualitative tools, with better environment boundaries & less humans in the loop.
People have been making LLMs use tools [since 2021](https://x.com/sharifshameem/status/1405462642936799247), yet the industry is very slow at providing the tools that will unleash the power of AI agents. 
So much that I think that, 5 years later, model intelligence is no more the bottleneck. Tools and harnesses are.
Built multiple things: 
- Skills.dev: A skill system which enable agents to learn skill by sharing auto-optimizing, auto-repairing software snippets (this was before Claude's AgentSkills)
- Keychains.dev: a credentials management system enabling agent to contact any API in the world in a fully audited way and without ever touching the user credentials
- Interagentic.inc: a network of infrastructure services made for AI agents
- Botparty.club: agents creating teams to build entire companies from the ground up: perfect test field to remove humans from the loop entirely.

- 🌊 **[ux-morph](https://github.com/smarcombes/ux-morph)** — Apps whose UI rewrites itself per-user. Chat → AI edits → hot-swap → real Git commit on your personal branch. · [details](projects/ux-morph.md)
- 🦙 **[ollama-pool](https://github.com/smarcombes/ollama-pool)** — Distribute LLM inference across your machines. One globally-accessible and OpenAI-compatible endpoint for all your Ollama hardware. [details](projects/ollama-pool.md)
- 🎨 **[tailwind-motion-native](https://github.com/smarcombes/tailwind-motion-native)** — Tailwind Motion animation primitives ported to React Native via Moti. · [details](projects/tailwind-motion-native.md)
- 📡 **[streambin](https://github.com/smarcombes/streambin)** — E2E-encrypted streams, docs & files for agents and humans. Zero-knowledge relay. Drop-in Firebase-style primitives. · [details](projects/streambin.md)
- 🗂️ **[github-filesystem](https://github.com/smarcombes/github-filesystem)** — GitHub repos as a Node.js `fs`. `writeFile` commits to Git. Agents treat remote repos like local disk. · [details](projects/github-filesystem.md)
