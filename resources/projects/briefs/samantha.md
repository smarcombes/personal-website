# Samantha

> Multi-device AI assistant inspired by *Her*. Knows your contacts, controls your desktop, speaks with expressive voice.

[![TypeScript](https://img.shields.io/badge/-TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)](#)
[![Year](https://img.shields.io/badge/2025-lightgrey?style=flat-square)](#)

The thesis: an AI assistant that truly knows you, works across all your devices, and gets better over time by learning from your actual digital life — not from a prompt you wrote once.

## What it did

**Knowledge graph from email**: parsed your Gmail, extracted people, companies, and projects as structured entities, auto-maintained a "flashcard" for every contact (rendered as Tailwind HTML, generated by `gpt-4o-mini`). Ask about someone you emailed six months ago — it knew them.

**Context injection on every turn**: system prompt enriched with the user's profile, live location (geocoded), active devices, and entities detected in the current conversation. Cerebras (`llama3.3-70b`) for fast entity name extraction; `gpt-4o-mini` for structured enrichment.

**Desktop agent**: Electron tray app running Open Interpreter. Listened to a Firebase queue, executed natural-language commands via `node-pty`. Control any macOS app from your phone.

**Expressive voice**: Orpheus TTS on RunPod, WebSocket streaming. Before OpenAI's voice was good enough.

**Generative UI**: Cerebras decides whether to show a UI card for each message; if yes, generates Tailwind HTML inline in the conversation.

## Multi-device

Web (Next.js) · Mobile (PWA, home-screen installable) · Desktop (Electron tray) — all sharing context through Firebase Realtime Database.

## What we learned

The core experience was impressive. But repeatability was the killer: ask "list my emails" three times, get three different approaches, two fail. Agents re-invent the integration from scratch on every call.

This directly led to building [skills.dev](./skills-dev.md) — a shared registry of proven, tested capabilities so agents never solve the same problem twice.
